# 火车头队 · 智能车代码（RT1064）

本仓库包含两个阶段：**资格赛定稿（`run/4`）** 与 **校赛版本（`run/5`）**。
资格赛代码原样保留作为归档，后续改动都在 `run/5` 上继续。

| 项目 | 内容 |
| --- | --- |
| 队伍 | 火车头队（SEU-huochetou） |
| 主控 | NXP i.MX RT1064（逐飞科技核心板） |
| 驱动库 | 逐飞 SeekFree `zf_common` / `zf_driver` / `zf_device` |
| 摄像头 | MT9V03X（188×120，Otsu 二值化） |
| 屏幕 | TFT180（128×160 竖屏） |
| 开发环境 | Keil MDK 5 + ARMCC6 |

## 版本对照

| 目录 | 阶段 | 状态 | 说明 |
| --- | --- | --- | --- |
| `run/4` | 资格赛 | 已完赛，归档 | 含直道加速、倒车、三档速度等按里程标定的策略 |
| `run/5` | 校赛 | **当前主线** | 删除非普适模块，只保留与赛道形状无关的能力 |
| `run/6` | 校赛实验 | 未推送 | 在 `run/5` 上做环岛左右对称、自救对称 |

- 资格赛版本的完整说明见本文后半部分，以及 `run/4/README.md`。
- 校赛版本的改造思路、删减清单、参数与已知问题见 **[`run/5/校赛改造说明.md`](run/5/校赛改造说明.md)**。

## 二、校赛版（`run/5`）要点

### 改造原则

资格赛里有大量"按固定里程触发"的策略（直道加速 90000~105000、红砖左移 90000~120000、
倒车 8000 计数、三档速度）。校赛赛道未知，同样的里程对应完全不同的位置，因此整块删除，
只保留从图像本身出发的能力。

### 删除

`boost_process.c/.h`（直道加速、激进加速、红砖左移）、`reverse_process.c/.h`（倒车）、
三档速度与对应按键、舵机变化率限制、青色左移显示、"只处理前两个十字"限制。

### 保留

基础巡线、单边补偿、丢线自救、十字识别与补线、环岛状态机（`ring_s1`~`ring_s4`）、斑马线。

### 新增

**十字扫描降频**（`img_process.c`）：只把 `cross_detect()` 降到每 2 帧一次，
十字状态机仍每帧推进。`CROSS_SCAN_PERIOD` 设 1 可恢复每帧扫描。

### 参数

| 参数 | 位置 | 值 |
| --- | --- | --- |
| 目标速度 / PWM 上限 | `pid.c` | 30 / 1800 |
| 转向增益 | `main.c` | 0.50 |
| 前瞻中心行 / 半径 | `main.c` | 85 / 10 |
| 丢线自救 | `main.c` | 保持 1 帧，+0.6/帧，上限 3.5，25 帧超时 |
| 十字扫描周期 | `img_process.c` | 2 帧 |

## 三、资格赛版（`run/4`）元素实现

### 1. 普通巡线

- 加权前瞻：以 **85 行**为中心，取 **75~95 行**
- 三角权重，只累计有效行并重新归一化
- 转向：`duty = 中值 − 误差 × 增益`

### 2. 丢线自救

触发条件：控制窗口内有效中线行数为 0。

| 阶段 | 行为 |
| --- | --- |
| 前 1 帧 | 保持原舵角 |
| 之后 | 沿最后方向逐帧加大打角，每帧 +0.6，上限 3.5 倍 |
| 十字处理期间 | 只保持，不放大 |
| 超过 25 帧 | 回中直行 |

### 3. 十字

- 四角点识别 + 出口拟合，重建中线标记 `valid = 3`
- 资格赛版**上电后只处理前两个十字**；校赛版已取消该限制

### 4. 环岛

- 5 状态有限状态机，状态 2、3 共用状态 1 的拉线半宽表，状态 4 用内岛轮廓补线
- 资格赛版环岛期间转向增益统一 **0.30**（校赛版随加速模块一起删除该分段）

### 5. 斑马线

- 黑条计数 + 连续 3 帧确认，通过时补线
- 第二次通过后请求停车

```
识别 → 等 5 帧 → 目标速度 2 拍归零 → 反向制动
反向制动：K=50，上限 1600，最小保持 500，最长 400ms
转速 < 1 或超时 → 断电锁死
```

### 6. 倒车回起点（仅 `run/4`）

```
0 空闲 → 1 等停稳（连续8帧速度≤2）→ 2 倒车 → 3 刹车 → 4 完成
```

倒车距离 8000 计数，PWM 1200，纠偏 中线误差 × 0.30。

### 7. 直道加速（仅 `run/4`）

| 开关 | 引脚 | 区间 | 速度 | PWM 上限 | 增益 |
| --- | --- | --- | --- | --- | --- |
| 开关1 | C27 | 90000~105000 | 36 | 2500 | 0.30 |
| 开关2 | C26 | 90000~100000 | 40 | 3200 | 0.30 |

含减速段反向制动、直道中线左移 9 像素、加速段慢打舵机、出环后 10000 计数冷却。

## 七、已知限制

### 校赛版（`run/5`）

1. **弯道偶发直冲**：两侧边界正常、状态为 0 时舵机突然回正。
   最可疑是 `zebra_process()` 把弯道里的横向黑色接缝误判成斑马线，
   用两个锚点直连补线，把控制窗口覆盖成直线。排查方向见 `run/5/校赛改造说明.md`。
2. **只支持左侧环岛**：判据写死"左边丢 + 右边直"。左右对称版在 `run/6`。
3. **增益 0.50 是低速下调通的**，提速后需重新确认。

### 资格赛版（`run/4`）

1. 里程写死：加速区间、倒车距离按资格赛赛道标定
2. 中线左移依赖直道判定，弯道不触发
3. 环岛增益偏低（0.30），进环跟随略慢
4. 按键短按可能丢失（`key_scanner()` 状态存活 10 ms，主循环 20 ms 轮询）
5. 直道轻微高频抖动，怀疑与斑马线检测的 CPU 负载有关
