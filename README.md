## 二、赛道元素与处理方式

### 1. 普通巡线

- 加权前瞻：以 **85 行**为中心，取 **75~95 行**（共 21 行）
- 三角权重，只累计有效行并重新归一化
- 转向：`duty = 中值 − 误差 × 增益`

### 2. 丢线自救（`main.c`）

触发条件：控制窗口内有效中线行数为 0。

| 阶段 | 行为 |
| --- | --- |
| 前 1 帧 | 保持原舵角 |
| 之后 | 沿最后方向逐帧加大打角，每帧 +0.6，上限 3.5 倍 |
| 十字处理期间 | 只保持，不放大 |
| 超过 25 帧 | 回中直行 |

### 3. 十字（`img_process.c`）

- 四角点识别 + 出口拟合
- **上电后只处理前两个十字**（`cross_completed_passes >= 2` 后跳过），避免误触发
- 十字重建的中线标记为 `valid = 3`

### 4. 环岛（`ring_process.c`）

- 5 个状态的有限状态机
- 状态 2、3 共用状态 1 的拉线半宽表
- 状态 4 用内岛轮廓补线
- 环岛期间转向增益统一 **0.30**

### 5. 斑马线（`img_process.c`）

- 黑条计数识别 + 连续 3 帧确认
- 通过补线（绿色中线参与转向）
- **第二次通过后**：连续 5 帧无候选 → 请求停车

**停车时序**（`isr.c`）：

```
识别 → 等 5 帧（约100ms）→ 目标速度 2 拍归零 → 反向制动
反向制动：K=50，上限 1600（16%），最小保持 500，最长 400ms
转速 < 1 或超时 → 断电锁死
```

### 6. 倒车回起点（`reverse_process.c`）

盲盒任务：过斑马线停车后倒车回到起点。

```
0 空闲 → 1 等停稳（连续8帧速度≤2）→ 2 倒车 → 3 刹车 → 4 完成
```

| 参数 | 值 |
| --- | --- |
| 倒车距离 | 8000 计数（+ 惯性约 400 = 8400） |
| 倒车 PWM | 1200（12%） |
| 倒车纠偏 | 中线误差 × 0.30，方向取反 |
| 刹车 | 与斑马线停车同强度 |

### 7. 直道加速（`boost_process.c`）

**两套硬件开关，独立选择**：

| 开关 | 引脚 | 区间 | 速度 | PWM 上限 | 增益 |
| --- | --- | --- | --- | --- | --- |
| 开关1 | **C27** | 90000~105000 | 36 | 2500 | 0.30 |
| 开关2 | **C26** | 90000~100000 | 40 | 3200 | 0.30 |

- 开关2 之后有 **10000 计数减速段**：40 → 30 线性回落 + 反向制动（K=120，上限 28%）
- **中线左移**：两开关下 90000~120000 区间，直道可靠（双边行≥18 且单边行≤3）时左移 **9 像素**，屏幕标青色
- **慢打舵机**：加速段与减速段内舵机每帧最多变 **2°**
- **环岛冷却**：出环后编码器再走 **10000 计数**才允许提速

| 按键 | 引脚 | 档位 | 说明 |
| --- | --- | --- | --- |
| KEY4 | **C12** | **L** | 30 / 1500 |
| KEY3 | **C13** | **M**（默认） | 30 / 1800 |
| KEY2 | **C14** | **H** | 十字前同 M；**十字后 32 / 2000 / 增益0.50** |
| KEY1 | **C15** | 复位 | 斑马线/十字/环岛/倒车/加速状态全部清零，回 M 档 |

**屏幕显示**（第一行右侧）：

| 显示 | 含义 |
| --- | --- |
| `L` / `M` / `H` | 当前档位 |
| `HL` | H 档 + 开关1（C27） |
| `HH` | H 档 + 开关2（C26） |

## 七、已知限制

1. **里程写死**：加速区间、倒车距离都按资格赛赛道实测标定，赛道变化后必须重新标定
2. **中线左移依赖直道判定**：弯道中不会触发，红砖若出现在弯道则无法规避
3. **环岛增益偏低**（0.30）：为抑制过冲而降低，代价是进环跟随略慢
4. **按键短按可能丢失**：`key_scanner()` 的短按状态只存活 10 ms，主循环 20 ms 轮询，偶尔需要按两次
5. **直道轻微高频抖动**：怀疑与斑马线检测每帧运行的 CPU 负载有关，未最终定位
6. **未做元素通用化**：十字、环岛、斑马线均按本次赛道顺序调参，换赛道需重新验证
